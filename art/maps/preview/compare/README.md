# Owner art colour comparison

Each sheet has three panels in order: the untouched original source art, the fixed per-tile GBC fit used by the runtime maps, and the actual mono/DMG rendering selected by the owner's legacy scenes.

The chosen runtime approach for new maps is the **fixed per-tile GBC fit**. It keeps each original tile's luminance edges, assigns it to the shared owner bank, and keeps facade, paving and planter patches coherent across neighbouring tiles. The day bank uses muted ramps sampled from the owner's warm plaster, yellow grass, slate and blue-glass colours; the brick slot is warm plaster/ochre with a muted mauve shade 3 so paving does not become fluorescent. The shared palette resources are regenerated from the same bank by `build_game.py`. The original B7 scenes continue to use the third, actual mono panel so their source detail is preserved without pretending that their warm RGB hues survive DMG rendering.

GB Studio's fixed `ColorizedImage.worker.ts` explains the earlier salmon result: each pixel is reduced only by its green channel (`g < 65`, `< 130`, `< 205`), then that index is looked up in the tile's palette (`tiles[t] & 0x7`). The worker does not preserve arbitrary RGB source colours, and warm facade tiles assigned to the brick slot therefore render with that slot's ramp. The runtime maps now use canonical four-shade tiles, explicit `tileColors`, and the muted shared `muj-*` banks, so the editor and game agree on the selected owner fit. The mono panel uses the same green-channel thresholds and GB Studio's `dmg` colors; GB Studio's AutoColor worker remains a separate palette solver and is not represented by a local approximation in these comparison sheets.
